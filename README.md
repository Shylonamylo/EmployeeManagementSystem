# Система учета сотрудников | Курсовая работа
Это система позволяет:
1. Просматривать, добавлять, увольнять и редактировать сотрудников
2. Назначать сотрудникам задачи
   
    2.1 Менять название задачи и ее описание
   
    2.2 Менять срочность задачи
   
    2.1 Назначать сотрудников для задачи
   
3. Назначать премии
    3.1 Указывать причину премии
   
    3.2 Указывать сотрудника, который получит премию
   
4. Проводить рассчет зарплат

    4.1 Суммировать премии и зарплату сотрудников
   
    4.2 Проводить рассчеты с учетом налогов
5. Импорт и Экспорт данных в Excel

При запуске программы открывается окно авторизации для защиты от несанкционированного доступа

При успешной авторизации пользователь попадает в главное меню

Настройки: 

Данные для подключения к серверу MySQL

Текущие налоги

Главное меню:

Боковая панель с возможностью скрытия

Боковая панель:

Перемещения по категориям, а также кнопка для открытия настроек
